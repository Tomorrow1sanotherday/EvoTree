# Spec 2026-09-02 - M2 五任务三组最终验收

## 验收范围

在 A800 上对固定五个 OSWorld 任务串行运行 `baseline`、`frozen` 和 `online` 三组。
三组使用相同模型、任务顺序、`max_steps`、observation 配置和 CPU/TCG 虚拟机；
`frozen` 与 `online` 从相同 seed memory 复制，前者关闭写入，后者允许整轮结果写回。

结果目录：

```text
/data/songweishuai/evotree_m2_final_20260902
```

五个任务为设置 Terminal 默认尺寸、设置系统音量、放大文本缩放、从 Trash 恢复文件、
开启 Do Not Disturb。每个 arm 的 `run.json.returncode` 均为 `0`，因此三组基础设施均
完整跑完 5/5。

## 结论

- OSWorld-MCP 真实 agent 接入闭环成立：prompt 能注入 `[经验]`/`[注意]`，轨迹包含真实
  MCP function call，最终 evaluator score 通过 `runtime.finish(score=...)` 写回经验树。
- `frozen` 的 memory 前后 hash 完全一致，确认只读评测不会污染 seed；`online` 的 hash
  发生变化且生成 6 个 `tree.json`，确认在线写入生效。
- M1 已验证同任务 MCP 短路径的 TIR 排序机制：MCP `val=0.81000` 高于 GUI
  `val=0.65610`。但本次 M2 仅 5 个任务且模型轨迹存在随机性，online mean score
  `0.2` 未超过 baseline `0.4`，不能据此声称 benchmark 增益已经复现。后续应在固定
  任务集上重复配对实验并报告均值、方差和失败路径。
